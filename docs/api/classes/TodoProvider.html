    Class TodoProvider

    Управляет поиском задач и их отображением в боковой панели TODO Explorer.

    Remarks

    Реализует TreeDataProvider для интеграции с VS Code TreeView. Хранит результаты в Map, поддерживает полное сканирование рабочей области и инкрементальное обновление при сохранении или удалении файлов.

    Во время полного сканирования события изменений откладываются, а затем применяются к новому кешу. Это защищает результаты от потери изменений, пришедших непосредственно во время обхода проекта.

    refresh

    • refresh(): Promise<void>

      Полностью сканирует рабочую область VS Code в поисках TODO и FIXME.

      Returns Promise<void>

      Promise, который завершается после обновления результатов.

      Remarks

      Файлы ищутся посредством workspace.findFiles(); служебные каталоги исключаются, а ресурсы размером более 1 МиБ пропускаются. Прогресс отображается стандартным уведомлением VS Code.

      Новые результаты собираются в отдельную Map и затем заменяют кеш. Сохранения и удаления, произошедшие во время обхода, применяются после его завершения. Повторный запуск при активном поиске игнорируется.
